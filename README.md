# Hadith-Narrators-site

Cerh-Taʿdîl · Kaynak Kontrolü sayfasının yayımlanan kopyası.

Adres: https://ramazan9838.github.io/Hadith-Narrators-site/

Bu depo yalnız yayımlanan sayfayı (`index.html`) taşır; kaynak kod ve çalışma verileri ayrı, özel bir depodadır. Dosyayı elle düzenlemeyin; yeni sürüm sayfanın içinden (Ayarlar) üretilip `index.html` yerine konur.

`claude/…` dalına gönderilen yeni kopya `.github/workflows/ana-dala-birlestir.yml` ile `main`’e kendiliğinden birleşir ve GitHub Pages derlemesi istenir. Dal yalnız `index.html`, `README.md` ve `.nojekyll` dosyalarını değiştirebilir; `index.html` şifreli bir kopya değilse ya da şifresiz râvi verisi taşıyorsa birleştirme yapılmaz.
